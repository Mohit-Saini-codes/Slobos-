Cyber Detective Protocol

About This Simulation

Cyber Detective is a beginner-friendly digital forensics and cybersecurity investigation game. You step into the shoes of an incident responder tasked with unraveling realistic simulated cyber events.

Investigation Workflow

  1. Examine Evidence: Read server logs, support tickets, network records, and file metadata.
  2. Extract Clues: Identify timestamp mismatches, abnormal source IPs, and credential anomalies.
  3. Synthesize Theory: Access the Deduction Board to select the perpetrator and vector.

Safety & Ethics Standard

All IPs, domains, usernames, and server logs are purely fictional. This exercise runs 100% locally in your browser.
